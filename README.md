# 📚 Tasks Overview

| Task | Topic | Contents |
|------|-------|----------|
| ✅ Task 1 | Vectorized Scaled Dot-Product Attention | Implemented scaled dot-product attention from scratch using NumPy, including batch processing, masking, and attention score computation. |
| ✅ Task 2 | Byte Pair Encoding (BPE) & Causal Language Model | Built a custom BPE tokenizer and implemented an autoregressive causal language model training pipeline. |
| ✅ Task 3 | Local LLM Quantization & Logit Extraction | Loaded a local Llama model, explored quantization techniques, and extracted token logits for analysis. |
| ✅ Task 4 | HNSW Vector Indexing | Developed a Hierarchical Navigable Small World (HNSW) vector indexing algorithm for efficient similarity search. |
| ✅ Task 5 | Transformer Backpropagation | Implemented manual backward propagation for self-attention and tracked gradients without PyTorch autograd. |
| ✅ Task 6 | Asynchronous RAG Pipeline | Built a Retrieval-Augmented Generation (RAG) pipeline using FastAPI, FAISS, LangChain, and Cross-Encoder reranking. |
| ✅ Task 7 | LoRA Fine-Tuning | Implemented Low-Rank Adaptation (LoRA) for efficient parameter fine-tuning of transformer models. |
| ⏳ Task 8 | Multi-Agent Collaborative Swarm | Design of a multi-agent system using AutoGen, Redis, PostgreSQL, and Docker. |
| ⏳ Task 9 | Real-Time Vector Streaming | Streaming vector ingestion using Kafka, PySpark, and Qdrant for dynamic indexing. |
| ⏳ Task 10 | Diffusion Models (DDPM) | Forward and reverse diffusion implementation for image generation from Gaussian noise. |
| ⏳ Task 11 | Prompt Injection Guardrails | Developed security guardrails to detect and mitigate prompt injection attacks in LLMs. |
| ⏳ Task 12 | Knowledge Distillation | Compressed large vision-language models using teacher-student training strategies. |
| ⏳ Task 13 | Direct Preference Optimization (DPO) | Implemented preference-based fine-tuning using chosen/rejected response pairs. |
| ⏳ Task 14 | CUDA Kernel Programming | Built custom CUDA kernels for optimized activation functions in PyTorch. |
| ⏳ Task 15 | Enterprise LLM Gateway | Designed a scalable LLM gateway with rate limiting, failover, monitoring, and request routing. |
